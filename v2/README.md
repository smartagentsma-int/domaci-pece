# Domácí Péče

Next.js app for a premium healthcare agency landing page.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   npm run start
   ```

## Notes

- Uses the `app/` router with Tailwind CSS and a smooth 3D background.
- `next.config.js` allows external images from `images.pexels.com`.
- This repo is ready for both development and production deployment.
